# CALLS — filing rules

Add-only archive of call transcripts and recordings. Files are never
edited and never renamed once filed.

## Naming

```
YYYY-MM-DD-<who>-<what>.<ext>
```

- `who`: the counterparty, lowercase (`joel`, `coldcalls`, a client name).
- `what`: two or three words, lowercase, hyphenated (`fourth-call`,
  `stanislaus-batch-01`, `onboarding-walkthrough`).
- Same day, same counterparty twice: append `-2`, `-3`.

Examples: `2026-08-15-joel-fourth-call.txt`,
`2026-08-18-coldcalls-stanislaus-batch-01.mp3`.

## For any AI filing a drop-off

When Kenzo hands over an untitled transcript or recording ("this is a
call recording, name it and put it away"):

1. Determine the date, the counterparty, and a two-or-three-word topic —
   from what he says first, from the content second; ask only if neither
   settles it.
2. Rename to the format and place it here.
3. Never edit the contents. Never touch existing files.
4. If the call contains decisions or commitments that change current
   work, surface them to Kenzo and reflect them in `../../STATE.md` —
   the file itself stays untouched.

Interview and calls 1–4 carry estimated dates (fourth call's
2026-08-15 is confirmed); if Kenzo ever supplies exact dates, renaming
those five is the one sanctioned exception to rule 3.
